# Security Review

Read `.agentic/SECURITY.md`, manifest permissions, installed policies, architecture, data/API docs, relevant ADRs, and lockfile before review.

Assess assets, trust boundaries, authentication, authorization, tenancy, input/output handling, secrets, cryptography, privacy/retention, dependencies/supply chain, CI/release, logging, backups/recovery, abuse cases, migration safety, and operational response.

Ground findings in repository evidence. Distinguish deterministic scanner results from judgment. Never claim a baseline secret scan or file-presence check proves security. High-impact fixes and policy/permission changes require explicit approval.
