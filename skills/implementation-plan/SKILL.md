# Implementation Plan

Create substantial work plans under `.agentic/plans/active/` using `YYYY-MM-DD-short-title.md`.

Include goal, scope/non-scope, current evidence, assumptions, affected boundaries, ordered steps, data/schema changes, security/permission implications, test/eval plan, rollout, rollback, observability, risks, dependencies, and completion criteria.

A plan may reference accepted ADRs and current truth but cannot redefine them. On completion, record outcome and move the plan to `.agentic/plans/archive/`; update ADRs/current truth only when a durable accepted decision changed.
