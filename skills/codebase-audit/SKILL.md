# Codebase Audit

Perform an evidence-backed audit of the repository. Inspect structure, architecture, maintainability, tests, security, dependencies, performance evidence, documentation, agent instructions, operations, and design-system compliance when active. Separate deterministic observations from interpretation. Report severity, evidence, impact, and recommended remediation. Use `ah audit` as a structural baseline, not as a substitute for dependency scanning, runtime testing, coverage, visual review, or production evidence.
