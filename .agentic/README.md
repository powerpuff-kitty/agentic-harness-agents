# Project context

This directory governs the `agentic-harness-agents` repository itself. Canonical ecosystem architecture remains owned by `agentic-harness`; this repository owns agent procedures.

Read `manifest.yaml`, then the relevant product/architecture/security truth and ADRs. Root `skills/`, `prompts/`, `adapters/`, `references/`, and `evals/` are distributable product content; `.agentic/` is this repository's own project context.
