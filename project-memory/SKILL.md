# Project Memory

Use retained project knowledge without allowing stale or untrusted material to
replace accepted project truth. Establish the task, mandatory instructions/current
source, memory provider/artifacts, query scope, permitted local/remote processing
and requested retrieval or curation action. No memory backend is required.

1. Read required project truth first. Retrieve only for unresolved task questions;
   use explicit project/repository/path/time scope and relevance. Do not load an
   entire store simply because it exists. Use the [method](references/method.md).
2. Apply sensitivity restrictions before any remote handoff. local_only items stay
   local even for a high-confidence match. If no permitted provider exists, inspect
   supplied local artifacts or report the missing capability; do not provision one.
3. Check identity, provenance, state, validity window and source changes. Exclude
   expired, stale, invalidated, superseded and consolidated inputs as current advice;
   follow lineage to usable successors. Candidate status is not acceptance.
4. Reconcile conflicts against accepted truth and current evidence. Preserve both
   historical records and explicit uncertainty; confidence/relevance scores do not
   settle authority. Return included and excluded IDs with reasons and verification.
5. For promotion, require a reusable project-specific statement, permitted evidence,
   current scope, sensitivity and a duplicate check. Reject transient status, secrets,
   raw transcripts, unsupported generalizations and already represented lessons.
6. Propose promotion/reverification/supersession/consolidation with provenance.
   Persist only when the task authorizes that actual store mutation; preserve lineage
   and old evidence. Never overwrite canonical truth through a memory operation.
7. Deliver the [retrieval/curation report](assets/report-template.md), actual queries,
   included/excluded IDs, contradictions, candidate decisions and performed versus
   proposed operations. For requested Harness serialization use the canonical
   [mapping](references/protocol.md); guidance itself works without the CLI/provider.

## Completion

Memory use is bounded, traceable and current enough for its stated purpose. Remote
privacy filters, acceptance and writes have actual evidence or remain unperformed.
