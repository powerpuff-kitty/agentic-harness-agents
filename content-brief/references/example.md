# Example: a product onboarding article

Input: a time-tracking app has an approved CSV import feature, no accounting
integration, and a support audience migrating spreadsheets. No keyword dataset.

Useful brief: explain how to prepare columns, preview an import and resolve invalid
rows. Ask for the supported schema/error examples before prescribing exact steps.
Use the product documentation as the feature authority. The reader's next action
is a preview import. An article passes when supported steps work against the named
version and the error example has a documented recovery.

Avoid claiming “the most searched migration question,” inventing import throughput,
or promising accounting synchronization. Search demand is unmeasured. If a related
article already owns the same intent, recommend updating it with a defined delta.

For web content, consult current [Google people-first content guidance](https://developers.google.com/search/docs/fundamentals/creating-helpful-content).
