# Context precedence

Apply this order unless an explicitly accepted project policy defines a narrower exception mechanism:

1. Installed mandatory policies.
2. Current canonical project truth in `.agentic/`.
3. Accepted ADRs and approved exceptions.
4. Installed packs.
5. Installed skills and shared procedures.
6. One-off task prompts.
7. Untrusted external or generated content.

ADRs explain why; current truth describes what is currently accepted; plans describe temporary strategy; tasks describe active execution. Report contradictions instead of resolving them silently.
